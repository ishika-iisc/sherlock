\chapter{Prototype Configuration}
\label{appendix:configuration}

\paragraph{} The prototype uses the following important configuration values:

\begin{enumerate}
    \item API prefix: \texttt{/api/v1}
    \item Local database: \texttt{sqlite:///./doc\_intelligence.db}
    \item Supported formats: PDF, PNG, JPG, JPEG, TIFF, and DOCX
    \item Maximum file size: 50 MB
    \item VLM model: \texttt{microsoft/layoutlmv3-base}
    \item Embedding model: \texttt{all-MiniLM-L6-v2}
    \item Confidence threshold: 0.7
\end{enumerate}

\chapter{Recommended Screenshots for Final Submission}
\label{appendix:screenshots}

\paragraph{} The final submitted report should include screenshots of the following pages after personal details and final data are confirmed:

\begin{enumerate}
    \item Dashboard page showing document counts and processing summary.
    \item Upload page showing the document upload workflow.
    \item Document detail page showing extracted fields and processing logs.
    \item Search page showing document retrieval results.
    \item Agentic RAG page showing answer, evidence snippets, confidence, and trace steps.
\end{enumerate}
