==============================================
Final Project Report Template for MTech Online
==============================================

This folder contains the template files required for formatting your final project report. LaTeX and MS Word templates are given in the two sub-folders. The recommended option is LaTeX using the online Overleaf website.

== LaTeX ==
Create a new project on Overleaf.com and upload the files present in the latex sub-folder. Under the Menu, set main.tex as the main LaTeX document for compilation.

Modify main.tex to set the relevant variables such as author (student name), title of project, etc. (line 104 onwards). Uncomment the relevant stream name.

Enter the contents of your project report in the following files: abstract.tex, acknowledgements.tex, nomenclature.tex, chap_introduction.tex, chap_literature_review.tex, chap_methodology.tex, chap_experiments_and_results.tex, chap_conclusion.tex and references.bib. If you are adding more chapter files or removing some of them, update the input declarations in the main.tex file accordingly (line 253 onwards).

Compile the project and generate the PDF. Make sure there are no errors or warnings. Submit the generated PDF document.


== Microsoft Word ==
Install the font files present in the word sub-folder (*.ttf) using Windows or MacOS.

Open the project-report-template.docx document and fill in the details of your title, student name, etc. that are highlighted using comments. Remove the comments once you fill the relevant details.

Edit the document with your project details. Make sure to follow the format template that is given for the Chapter headings, section, sub-section headings and regular text.

Update the list of tables/figures/algorithms and the table of contents. Update the references.

Print the Word document to PDF and submit the generated PDF document.
